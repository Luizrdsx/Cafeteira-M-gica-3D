# Cafeteira-Mágica-3D
Cafeteira 3D Interativa

Estrutura HTML de uma cafeteira com reservatório de água, 
compartimento de café, painel de controle e bico de saída para
xícara.

Sistema de vapor animado, botões de controle interativos em
JavaScript para controlar todas as animações e estados de processo.
_____________________________________________________________________

Funcionalidades:
☕ Adicionar Café - Abre a tampa, adiciona café moído e fecha
▶ Passar Café - Inicia a preparação com:
Água descendo do reservatório
Café fluindo pelo bico
Xícara enchendo progressivamente
LED amarelo pulsando
🔄 Resetar - Limpa tudo e volta ao estado inicial
